# 自定义「巅峰对决」BGM

游戏内置了一首**程序合成的**巅峰对决专属曲（更快、切分、警报音），开箱即用。

如果你想让巅峰对决放**自己的**音乐（比如 KPL 官方那首），把音频文件放到这个目录：

```
audio/peak.mp3     ← 优先
audio/peak.ogg
audio/peak.m4a
audio/peak.wav
```

进入第 7 局（3:3 巅峰对决）时会自动改用你的文件，其余场景仍用内置曲。

**注意**
- 文件名必须是 `peak`，扩展名在上面四个里任选其一。
- 浏览器只解码它支持的格式；`.mp3` 最稳，`.m4a`（AAC）在 Safari 上更稳。
- 音频版权请自行确认——官方 BGM 未经授权不要随仓库公开分发（本仓库不带任何音频文件，正是因为这个）。
- 想换回内置曲，删掉这个目录里的音频即可。
